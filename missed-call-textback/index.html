How it's built

In production this is a call-forwarding number with a missed-call webhook, a small serverless function that fires the reply through an SMS gateway within seconds of the call ending, and a CRM row written the moment that text sends — so the owner sees the lead land in their dashboard in real time. This page simulates all three with local JavaScript and a canned script. No call is placed and no text is sent anywhere.
