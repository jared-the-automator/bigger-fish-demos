    How it's built

    In production this is a validated web form posting to a webhook, a server-side scheduler that checks a real calendar for open slots before confirming one, a CRM insert for the new client record, and confirmation sends through an email API and an SMS gateway — all triggered by that one submission. This page simulates every step with local JavaScript timers. Nothing is booked, filed, or sent anywhere.
